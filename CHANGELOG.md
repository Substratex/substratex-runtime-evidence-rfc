# Changelog

## RFC Draft 1.0 — 2026-10-12

Initial clean-room RFC publication for the implementation-neutral Runtime Evidence Standard.

Introduces:

- RES core architecture and invariants;
- source qualification;
- canonical runtime;
- runtime evidence identity and provenance;
- support classes and explicit missingness;
- bounded findings;
- lifecycle objects and scoped issuance;
- challenge, counterevidence, review, and supersession;
- preservation/interchange requirements;
- conformance profiles;
- explicit RES/EGC handoff boundary;
- JSON Schema 2020-12 interchange drafts; and
- versioned vocabularies and canonical examples.

This RFC series is a new specification baseline. It does not incorporate prior product-specific standards text.
