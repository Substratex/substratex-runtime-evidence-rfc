# Namespace and Versioning

The provisional RES 1.0 namespace is:

`urn:substratex:res:1.0:`

Schema identifiers use:

`urn:substratex:res:1.0:schema:<name>`

Vocabulary identifiers use:

`urn:substratex:res:1.0:vocab:<name>`

The namespace is versioned because changes to object identity, field semantics, missingness meaning, lifecycle state, or conformance behavior may be breaking.

`1.0-draft` in example objects indicates RFC-track semantics. Stable RES 1.0 objects will use `1.0` only after the Candidate-to-Accepted transition.
