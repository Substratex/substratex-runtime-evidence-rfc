# RES 1.0 RFC Roadmap

## RFC Draft 1.0

- publish core architecture, lifecycle, schemas, vocabulary, and initial conformance fixtures;
- collect ambiguity and interoperability issues;
- implement at least one independent parser/validator;
- expand pass/fail corpus.

## Review

- freeze object names and missingness/support-class semantics;
- formalize deterministic identity test vectors;
- add round-trip preservation corpus;
- add challenge/supersession state-transition corpus;
- review mappings to provenance and telemetry ecosystems.

## Candidate

- freeze normative semantics except defect correction;
- publish machine-readable conformance report format;
- obtain at least two independently developed implementations for core interchange semantics;
- publish implementation reports.

## RES 1.0

- accept the stable RFC set;
- publish immutable versioned schemas and vocabularies;
- retain RFC history and errata process;
- distinguish conformance from any later certification program.
