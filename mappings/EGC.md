# Mapping Note — RES and Evidence-Governed Computation™

RES supplies evidence material and metadata needed by a claim-governance system:

| RES property | EGC use |
| --- | --- |
| evidence identity | binds a claim to an evidence object |
| source/canonical references | supports traceability |
| method identity | supports admissibility checks |
| support class | prevents semantic category inflation |
| scope | constrains claim scope |
| missingness | enables refusal/conditional outcomes |
| lineage | supports derivation inspection |
| challenge/review state | prevents stale authority |
| preservation metadata | supports egress/preservation continuity |

RES does not itself decide whether a proposition is admissible. EGC does not replace RES formation semantics.
