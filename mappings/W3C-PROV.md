# Mapping Note — RES and W3C PROV

RES provenance relations can be serialized or mapped into an external provenance graph where an implementation chooses to use W3C PROV concepts.

RES adds evidence-specific requirements that are outside a generic provenance mapping, including support class, missingness semantics, bounded finding scope, issuance objects, challenge state, and preservation fidelity.

This mapping is informative. Conformance to one specification does not imply conformance to the other.
